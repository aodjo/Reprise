# Privacy Policy — Reprise for YouTube Music

Effective date: August 5, 2026

This Privacy Policy applies to the Reprise for YouTube Music browser extension
(the "Extension").

## Single purpose

The Extension connects an active YouTube Music tab to the Reprise desktop app
running on the same device. This lets the user view now-playing information in
Reprise and send playback controls from Reprise to YouTube Music.

## Information the Extension handles

When the user opens `music.youtube.com`, the Extension may process:

- now-playing metadata, including the track title, artist, album, artwork URL,
  video identifier, and current track URL;
- playback information, including playback state, duration, position, volume,
  playback rate, and tab visibility; and
- operational information required for the local connection, including the
  Extension version, Extension identifier, browser type, and temporary tab or
  session identifiers.

The Extension does not access authentication credentials, cookies, personal
communications, financial information, health information, or browsing
activity on websites other than YouTube Music.

## How the information is used

The Extension uses this information only to:

- display the active YouTube Music session in the Reprise desktop app;
- keep playback state synchronized between YouTube Music and Reprise; and
- carry out user-requested play, pause, previous, next, stop, seek, and volume
  controls.

## Local processing and sharing

The Extension sends playback information only to the Reprise desktop app on
the same device through a loopback connection at `127.0.0.1`. It does not send
this information to a developer-operated remote server.

The Extension does not sell user data, share it with third parties, use it for
advertising, use it for credit decisions, or use analytics or tracking
services. All executable JavaScript is included in the Extension package; the
Extension does not download or execute remote code.

## Storage and retention

The Extension does not use browser storage or a remote database to retain the
playback information it reads. It keeps only the current tab and playback state
in memory for as long as needed to provide the local connection. Disabling or
uninstalling the Extension stops this processing.

## Host permission

The Extension requests access only to `https://music.youtube.com/*`. This
permission is necessary to read the active player's now-playing information and
playback state and to perform playback controls explicitly requested by the
user. The Extension does not request access to other websites.

## User choices

Users can stop the Extension from handling information at any time by disabling
or uninstalling it in the browser. Closing a YouTube Music tab stops that tab's
session, and closing the Reprise desktop app stops transfer to Reprise.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web
Store User Data Policy, including the Limited Use requirements. Information is
used only to provide or improve the Extension's disclosed single purpose.

## Changes to this policy

This policy may be updated when the Extension's functionality or legal
requirements change. The effective date above will be updated when a material
change is published.

## Contact

For privacy questions or requests, open an issue at
<https://github.com/aodjo/Reprise/issues>.

# 개인정보처리방침 — Reprise for YouTube Music

시행일: 2026년 8월 5일

이 개인정보처리방침은 Reprise for YouTube Music 브라우저 확장 프로그램
(이하 "확장 프로그램")에 적용됩니다.

## 단일 목적

확장 프로그램은 현재 YouTube Music 탭을 같은 기기에서 실행 중인 Reprise
데스크톱 앱에 연결합니다. 사용자는 Reprise에서 현재 재생 정보를 확인하고
YouTube Music의 재생을 제어할 수 있습니다.

## 처리하는 정보

사용자가 `music.youtube.com`을 열면 확장 프로그램은 다음 정보를 처리할 수
있습니다.

- 곡명, 아티스트, 앨범, 앨범 이미지 URL, 동영상 식별자 및 현재 곡 URL
- 재생 상태, 재생 시간, 현재 위치, 음량, 재생 속도 및 탭 표시 상태
- 로컬 연결에 필요한 확장 프로그램 버전과 식별자, 브라우저 종류 및 임시 탭
  또는 세션 식별자

확장 프로그램은 인증 정보, 쿠키, 개인 통신, 금융 정보, 건강 정보 또는
YouTube Music 이외 웹사이트의 탐색 활동에 접근하지 않습니다.

## 정보 이용 목적

확장 프로그램은 위 정보를 다음 목적으로만 사용합니다.

- Reprise 데스크톱 앱에 현재 YouTube Music 재생 정보를 표시
- YouTube Music과 Reprise 사이의 재생 상태 동기화
- 사용자가 요청한 재생, 일시정지, 이전 곡, 다음 곡, 정지, 탐색 및 음량 제어

## 로컬 처리 및 공유

확장 프로그램은 재생 정보를 같은 기기의 `127.0.0.1` 루프백 연결을 통해
Reprise 데스크톱 앱에만 전달합니다. 개발자가 운영하는 원격 서버에는 이
정보를 전송하지 않습니다.

사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고, 신용 평가,
분석 또는 추적에 사용하지 않습니다. 실행 가능한 JavaScript는 모두 확장
프로그램 패키지에 포함되어 있으며 원격 코드를 내려받거나 실행하지 않습니다.

## 저장 및 보유

확장 프로그램은 브라우저 저장소나 원격 데이터베이스에 재생 정보를 보관하지
않습니다. 로컬 연결 제공에 필요한 현재 탭과 재생 상태만 메모리에서
일시적으로 처리합니다. 확장 프로그램을 사용 중지하거나 제거하면 정보 처리가
중단됩니다.

## 호스트 권한

확장 프로그램은 `https://music.youtube.com/*`에만 접근 권한을 요청합니다.
이 권한은 현재 재생 정보와 상태를 읽고 사용자가 명시적으로 요청한 재생 제어를
수행하는 데 필요합니다. 다른 웹사이트에는 접근 권한을 요청하지 않습니다.

## 사용자 선택권

사용자는 브라우저에서 확장 프로그램을 사용 중지하거나 제거하여 언제든지 정보
처리를 중단할 수 있습니다. YouTube Music 탭을 닫으면 해당 탭의 세션이
종료되고, Reprise 데스크톱 앱을 닫으면 Reprise로의 전달이 중단됩니다.

## Chrome 웹 스토어 제한적 사용

Google API에서 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Chrome 웹
스토어 사용자 데이터 정책을 준수합니다. 정보는 공개된 단일 목적을 제공하거나
개선하는 데만 사용됩니다.

## 방침 변경

확장 프로그램의 기능 또는 관련 법적 요구사항이 변경되면 이 방침이 수정될 수
있습니다. 중요한 변경사항을 게시할 때 위 시행일도 함께 갱신합니다.
