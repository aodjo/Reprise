Reprise for Linux

A menu bar music controller for MPRIS players. Add one channel, and every later build in it arrives with your usual updates.

Release

Stable releases. Alpha and beta builds are excluded.

echo "deb [trusted=yes] https://aodjo.github.io/Reprise release main" | sudo tee /etc/apt/sources.list.d/reprise.list
sudo apt update
sudo apt install reprise

Beta

Preview builds from the beta stage only.

echo "deb [trusted=yes] https://aodjo.github.io/Reprise beta main" | sudo tee /etc/apt/sources.list.d/reprise-beta.list
sudo apt update
sudo apt install reprise

Alpha

Development builds from the alpha stage only.

echo "deb [trusted=yes] https://aodjo.github.io/Reprise alpha main" | sudo tee /etc/apt/sources.list.d/reprise-alpha.list
sudo apt update
sudo apt install reprise

Update

sudo apt update && sudo apt upgrade

Remove

sudo apt remove reprise
sudo rm /etc/apt/sources.list.d/reprise*.list

Packages are unsigned, which is what [trusted=yes] allows; they are served over HTTPS from GitHub Pages. An AppImage sits beside this page for running Reprise without installing anything.
